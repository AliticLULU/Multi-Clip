MemoClip —— 键值对便签小工具
==============================

一个轻量级的键值对管理工具，适合记录开发中常用的密钥、
密码、配置等键值对信息。

--------------------------------
怎么运行
--------------------------------
双击  TetraClip.exe  即可，免安装。
（依赖 Windows 自带的 .NET Framework 4.0+，无需任何额外环境。）

--------------------------------
界面
--------------------------------
一个干净的小窗口：

  ┌─────────────────────────────────────┐
  │  🔍 Search memos...      [➕ Add]  │
  │                          [✎ Edit]  │
  │                          [✕ Del]   │
  ├──────────────┬──────────────────────┤
  │  Key         │  Value              │
  ├──────────────┼──────────────────────┤
  │  deepseek密钥 │  sk-xxxxxxxxxxxx    │
  │  服务器面板密码 │  admin123456       │
  │  ...         │  ...                │
  ├──────────────┴──────────────────────┤
  │  3 memos                           │
  └─────────────────────────────────────┘

上方搜索框支持实时过滤（匹配 Key 和 Value）。
底部状态栏显示便签数量。

--------------------------------
操作方式
--------------------------------
添加：点击 [➕ Add] 按钮，或按 Ctrl+N
编辑：选中一行后点击 [✎ Edit]，或双击该行
删除：选中一行后点击 [✕ Del]，或按 Delete 键
搜索：点击搜索框直接输入，或按 Ctrl+F 聚焦搜索框

关闭窗口会最小化到系统托盘，不会退出程序。

--------------------------------
数据保存
--------------------------------
所有便签自动保存在：
  %APPDATA%\TetraClip\memos.dat
关闭窗口或退出时自动保存，下次启动自动恢复。

--------------------------------
托盘图标
--------------------------------
- 双击托盘图标：显示/隐藏窗口
- 右键菜单：显示/隐藏、开机自启、退出

--------------------------------
重新编译（可选）
--------------------------------
双击 build.bat 即可，使用 Windows 自带的 C# 编译器，无需联网或安装 SDK。

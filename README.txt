MemoClip —— 键值对便签工具
============================

一个漂亮的键值对便签管理器，适合记录密钥、密码、配置等。
基于 HTML/CSS/JS 构建，界面简洁美观。

--------------------------------
怎么运行
--------------------------------
双击  TetraClip.exe  →  自动在浏览器中打开便签界面
程序会驻留在系统托盘，右键可退出或设置开机自启。

也可以直接双击  memo.html  在浏览器中使用（功能完全一致）。

--------------------------------
界面
--------------------------------
  ┌──────────────────────────────────────┐
  │  📝 MemoClip              3 memos   │
  ├──────────────────────────────────────┤
  │  🔍 Search memos...  [+Add][Edit][X] │
  ├──────────────┬───────────────────────┤
  │  Key         │  Value               │
  │  deepseek密钥 │  sk-xxxxxxxxxxxx     │
  │  服务器面板密码 │  xxxxxxxxxxxxxx      │
  └──────────────┴───────────────────────┘

--------------------------------
操作方式
--------------------------------
➕ Add     — 添加新便签（或 Ctrl+N）
✎ Edit     — 选中后点击编辑（或双击该行）
✕ Del      — 选中后点击删除（或 Delete 键）
🔍 搜索框   — 实时过滤（匹配 Key 和 Value）
↑ ↓ 方向键 — 上下切换选中行
Enter      — 打开编辑
Esc        — 清除选中 / 关闭弹窗

--------------------------------
数据保存
--------------------------------
数据保存在浏览器的 localStorage 中，不会丢失。
数据与浏览器绑定 —— 换浏览器需要重新导入。

--------------------------------
托盘图标
--------------------------------
- 双击托盘图标：重新打开便签页面
- 右键菜单：打开便签、开机自启、退出

--------------------------------
文件说明
--------------------------------
TetraClip.exe  — 启动器（系统托盘 + 打开浏览器）
memo.html      — 便签界面（可单独使用）
Program.cs     — 启动器源码
build.bat      — 编译脚本

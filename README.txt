MemoClip —— 键值对便签桌面工具
================================

一个精美的桌面便签管理器，适合记录密钥、密码、配置等。
基于 WPF 构建，界面简洁美观。

--------------------------------
怎么运行
--------------------------------
双击  MemoClip.exe  即可，免安装。
（依赖 Windows 自带的 .NET Framework 4.0+，Win11 原生支持。）

操作方式
--------------------------------
Ctrl+N      — 添加新便签
Ctrl+F      — 聚焦搜索框
Esc         — 清除搜索
双击标题栏   — 最大化/还原
点击卡片上的 ✎ — 编辑该便签
点击卡片上的 ✕ — 删除该便签
点击「➕ Add Memo」— 添加新便签

关闭窗口会最小化到系统托盘，不会退出程序。

--------------------------------
数据保存
--------------------------------
所有便签保存在程序目录下的 data\memos.dat
程序退出时自动保存。

--------------------------------
托盘图标
--------------------------------
- 双击托盘图标：显示窗口
- 右键菜单：打开、开机自启、退出

--------------------------------
重新编译（可选）
--------------------------------
双击 build.bat，使用 Windows 自带的 MSBuild，
无需联网或安装 SDK。

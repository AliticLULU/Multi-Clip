TetraClip —— 四格剪贴板小工具
================================

给 Windows 增加 4 个剪贴板，弥补系统只有一个剪贴板的不足。
开发时需要来回粘贴多段内容时特别好用。

--------------------------------
怎么运行
--------------------------------
双击  TetraClip.exe  即可，免安装。
（依赖 Windows 自带的 .NET Framework，无需任何额外环境。）

--------------------------------
界面
--------------------------------
一个窄窄的小窗口，上下排列着 4 个粘贴框。
任意时刻有一个框处于“激活”状态 —— 它的边框是【蓝色】的。
激活的框 = 当前的系统剪贴板。

--------------------------------
怎么用
--------------------------------
A) 切换“激活框”（3 种方式任选）：
   - 程序窗口在最前时，直接按 ↑ / ↓ 方向键，在 4 个框之间循环切换。
   - 鼠标点一下某个框。
   - 在任意程序里按全局热键：Ctrl+Alt+1 / 2 / 3 / 4。
   切到哪个框，它的内容就立刻成为系统剪贴板，可马上去别处 Ctrl+V。

B) 往框里存内容：
   - 正常 Ctrl+C 复制，内容就会自动进入当前【蓝色】的那个框。
   - 也可以直接点进框里手动输入 / 编辑。

C) 取出粘贴：
   - 切到目标框（使其变蓝），然后去别处 Ctrl+V。

典型流程：
   切到框1，复制内容A  -> A 存进框1
   切到框2，复制内容B  -> B 存进框2
   要粘 A：切到框1 然后 Ctrl+V
   要粘 B：切到框2 然后 Ctrl+V

--------------------------------
其他
--------------------------------
- 点窗口右上角的 X 会最小化到【系统托盘】继续运行，
  双击托盘图标可重新打开。
- 托盘图标右键菜单：显示/隐藏、开机自启、退出。
- 四个框的内容会自动保存，下次打开自动恢复
  （保存在 %APPDATA%\TetraClip\slots.dat）。

--------------------------------
重新编译（可选）
--------------------------------
双击 build.bat 即可，使用 Windows 自带的 C# 编译器，无需联网或安装 SDK。

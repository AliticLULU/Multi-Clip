TetraClip —— 四格剪贴板 + 便签小工具
==========================================

给 Windows 增加 4 个剪贴板，弥补系统只有一个剪贴板的不足，
同时内置便签功能，方便记录密钥、密码等键值对信息。

--------------------------------
怎么运行
--------------------------------
双击  TetraClip.exe  即可，免安装。
（依赖 Windows 自带的 .NET Framework，无需任何额外环境。）

--------------------------------
界面
--------------------------------
程序有两个标签页：

[📋 Clipboard] — 原有的四格剪贴板
  上下排列 4 个粘贴框。任意时刻有一个框处于"激活"状态 —— 蓝色边框。
  激活的框 = 当前的系统剪贴板。

[📝 Memos] — 新增的便签功能
  上方有搜索框，输入关键词即可快速过滤下方的键值对列表。
  支持添加(+)、编辑(✎)、删除(✕)操作，双击某条记录也可编辑。
  所有便签自动保存，下次打开自动恢复。

--------------------------------
怎么用
--------------------------------
A) 切换"激活框"（3 种方式任选）：
   - 程序窗口在最前时，直接按 ↑ / ↓ 方向键，在 4 个框之间循环切换。
   - 鼠标点一下某个框。
   - 在任意程序里按全局热键：Ctrl+Alt+1 / 2 / 3 / 4。
   切到哪个框，它的内容就立刻成为系统剪贴板，可马上去别处 Ctrl+V。

B) 往框里存内容：
   - 正常 Ctrl+C 复制，内容就会自动进入当前【蓝色】的那个框。
   - 也可以直接点进框里手动输入 / 编辑。

C) 取出粘贴：
   - 切到目标框（使其变蓝），然后去别处 Ctrl+V。

D) 便签功能：
   - 切换到 📝 Memos 标签页。
   - 点击 + 按钮添加新的键值对（如：密钥名 → sk-xxxx）。
   - 在上方搜索框输入关键词，列表实时过滤。
   - 双击某条记录可编辑，选中后按 Delete 或点 ✕ 可删除。
   - 所有便签自动保存在 %APPDATA%\TetraClip\memos.dat。

典型流程：
   切到框1，复制内容A  -> A 存进框1
   切到框2，复制内容B  -> B 存进框2
   要粘 A：切到框1 然后 Ctrl+V
   要粘 B：切到框2 然后 Ctrl+V
   记密钥：切到 📝 Memos → 点 + → 输入 Key/Value → OK

--------------------------------
其他
--------------------------------
- 点窗口右上角的 X 会最小化到【系统托盘】继续运行，
  双击托盘图标可重新打开。
- 托盘图标右键菜单：显示/隐藏、开机自启、退出。
- 剪贴板内容自动保存到 %APPDATA%\TetraClip\slots.dat。
- 便签内容自动保存到 %APPDATA%\TetraClip\memos.dat。

--------------------------------
重新编译（可选）
--------------------------------
双击 build.bat 即可，使用 Windows 自带的 C# 编译器，无需联网或安装 SDK。
